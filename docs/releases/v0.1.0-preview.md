# TopoRealm Workflow 0.1.0 Preview

首个可公开安装的 Workflow 领域模块。目标是在 TopoRealm 的通用图基座上达到 Super Plumber v1.0.0 等同或更好的可观察工作流效果，同时保持领域与存储边界清晰。

## 已交付

- 七态任务、quick/standard/program、depends_on 并行与汇合、原子 claim、stale 识别。
- checkpoint、execution report、self/independent/human verification。
- retry budget、fallback、iteration 和建议型双轴 adjudicator。
- 12 个 `workflow.*` operations；CLI、MCP、Web 共用 Core snapshot、revision 和提交边界。
- 六个无前缀 Workflow Skills；Codex、Claude、Pi 三份独立宿主投影。
- 自包含 npm 制品，支持安装、原子注册、卸载无损读取和重装恢复。
- Windows、Linux、macOS 以及三宿主真实安装/调用矩阵。

## 重要边界

- 模块可以提供由 Core 调用的领域操作实现，但没有图存储写权限；所有图变更只能以 `MutationPlan` 形式交给 Core 提交。
- 不直接兼容旧 `.graph` / `NodeSchema`，不发布旧 `graph_*` MCP 别名或 `plumber-*` Skill 别名。
- 不提供 designer agent；设计由 `workflow-design` Skill 完成。`workflow-adjudicator` 仅为 suggested，不强制独立裁决，也不阻止 self passed。
- Core 0.1.x 不含出厂内置领域模块。research、exploration、domain-modeling 等在本版发布后独立开发，并分别完成连接、多插件组合与生命周期测试。
- 本版不包含模块市场、代码沙箱或复杂依赖解析系统。

## 验证

- `npm run verify` 覆盖类型检查、单元、领域契约、CLI/MCP、真实 Chromium、真实 tarball、dogfood、模块生命周期和三宿主 smoke。
- P01–P40 逐项证据见 `docs/acceptance/parity-evidence.md`。
- 三平台运行凭据见 `docs/acceptance/platform-matrix.md`；用户放行见 `docs/acceptance/human-acceptance.md`。

## 安装

```bash
npx -y @lukawi/toporealm@0.1.3 module add @lukawi/toporealm-workflow@0.1.0
```

本版本发布到 npm `preview` dist-tag，GitHub Release 标记为 prerelease。
