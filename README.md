# TopoRealm Workflow

`@lukawi/toporealm-workflow` is the official workflow domain module for
[TopoRealm](https://github.com/LUKAWI/toporealm). It provides workflow task
lifecycle, dependency scheduling, execution evidence, agent integrations, and
a dedicated Web contribution while leaving graph persistence to TopoRealm Core.

The package is under active development toward the `0.1.0` Preview release.

## Development

```bash
npm install
npm run verify
```

Requires Node.js 20 or newer.
